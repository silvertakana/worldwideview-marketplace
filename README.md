# WorldWideView Marketplace

Browse, publish, and install data source plugins for [WorldWideView](https://github.com/silvertakana/worldwideview) — the real-time 3D globe intelligence platform.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [https://marketplace.wwv.local:3002](https://marketplace.wwv.local:3002) to view the marketplace.

## Stack

- **Framework**: Next.js 16 (App Router)
- **Styling**: Vanilla CSS
- **Database**: SQLite via Prisma (`better-sqlite3` adapter)
- **Language**: TypeScript
